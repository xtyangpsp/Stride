# 🔄 Project Relocated & Renamed: StepMark

The project previously known as **Stride** has been officially renamed to **StepMark** to ensure a unique brand identity and avoid trademark conflicts in the office productivity software ecosystem. 

This repository (`Stride`) now serves exclusively as a historical redirection gateway for legacy links, Zenodo citations, and older web app traffic. Active development has completely migrated to the new repository.

## 🛠️ How to Update Your Local Clones

If you have an existing local clone of the old `Stride` repository, you can update your remote URL instantly without re-cloning. Run the following commands inside your local project folder:

```bash
# 1. Update the remote origin URL to the new StepMark repository
git remote set-url origin https://github.com/xtyangpsp/StepMark.git

# 2. Verify that the update was successful
git remote -v
```
